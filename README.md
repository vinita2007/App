# Python Application Development - Flask REST API

## Overview
A fully documented Python REST API built with **Flask** and integrated with an **SQLite database** supporting complete **CRUD operations** (Create, Read, Update, Delete)[span_3](start_span)[span_3](end_span).

## Key Objectives Achieved
1. **Flask Framework Setup:** Implemented clean routing, HTTP request methods (`GET`, `POST`, `PUT`, `DELETE`), and endpoint responses[span_4](start_span)[span_4](end_span).
2. **Database Integration:** Configured an SQLite database (`database.db`) with automated table creation and SQL execution[span_5](start_span)[span_5](end_span).
3. **API Validation:** Handled request payload validation and error handling[span_6](start_span)[span_6](end_span).

## API Endpoints
- `POST /items` - Create a new item
- `GET /items` - Retrieve all items
- `GET /items/<id>` - Retrieve a specific item by ID
- `PUT /items/<id>` - Update an existing item
- `DELETE /items/<id>` - Delete an item
